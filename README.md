Dies ist ein rundenbasiertes RPG-Spiel, das in Swift entwickelt wurde und eine dynamische Besetzung von Charakteren sowie strategische Gameplay-Elemente bietet.

Ich plane, das Spiel in Zukunft zu erweitern, indem ich zusätzliche Zufallsereignisse, weitere Gegner, Story-Elemente, Beute, narrative Ereignisse und eine Gruppenangriffsfunktion für die Guardians hinzufüge.

## 🛠️ Funktionen

* **Vielfältige Charaktere**: Eine Vielzahl von Helden und Gegnern, jeder mit einzigartigen Fähigkeiten und Werten.
* **Strategischer Kampf**: Rundenbasierte Kämpfe mit Heilungs-, Verteidigungs- und Angriffsaktionen.
* **Spezialfähigkeiten**: Jeder Charakter hat Zugang zu mächtigen Fähigkeiten, die den Kampfverlauf entscheidend beeinflussen können.
* **Dynamische Ereignisse**: Ereignisse wie das Beschwören neuer Gegner und Spezialbewegungen bringen Unvorhersehbarkeit ins Spiel.
* **Terminal-Animationen**: Farbige Nachrichten und Animationen sorgen für ein intensiveres Spielerlebnis.

# 🎮 Guardians-RPG 🇺🇸

Guardians of the Galaxy themed round-based RPG console game

## 🌟 Overview

This is a turn-based RPG game developed in Swift, featuring a dynamic cast of characters and strategic gameplay elements. Designed for enthusiasts of terminal-based games.

The game was created as part of the Coding Foundations module during my one-year training to become a Mobile App Developer, and I worked on it with great passion. I also plan to expand the game in the future by adding more random events, additional enemies, story elements, loot, narrative-driven events, and a group attack feature for the Guardians.

## 🛠️ Features

* **Diverse Characters**: A variety of heroes and enemies, each with unique abilities and stats.
* **Strategic Combat**: Turn-based battles with healing, defensive, and offensive actions.
* **Special Skills**: Each character has access to powerful skills that can turn the tide of battle.
* **Dynamic Events**: Events like summoning new opponents and special moves add unpredictability.
* **Terminal Animation**: Color-coded messages and animations enhance immersion.

## 💻 Requirements

* Swift programming language installed.
* A terminal that supports ANSI escape codes for colors and animations.

## 🎯 How to Play

1. Clone the repository.
2. Open the project in Xcode or your preferred IDE.
3. Run the main Swift file in the terminal.
4. Follow the on-screen instructions to control your characters and fight enemies.

Enjoy your adventure!

**Note:** This project was created as a learning and practice project during my professional training as a Mobile App Developer and is intended purely for personal use. It is in no way affiliated with Marvel or the Guardians of the Galaxy.
